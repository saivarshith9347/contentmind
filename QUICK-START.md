# ContentMind - Quick Start Guide

Get ContentMind running in 5 minutes.

---

## 🚀 Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Create `.env.local`:
```bash
HINDSIGHT_BEARER_TOKEN=your_hindsight_token_here
GROQ_API_KEY=your_groq_key_here
```

Get keys:
- **Hindsight**: https://hindsight.dev
- **Groq**: https://console.groq.com

### 3. Run Development Server
```bash
npm run dev
```

Open http://localhost:3000

### 4. Load Demo Data
1. Click "Load Demo Memory"
2. Wait ~10 seconds
3. Explore the app!

## 🐛 Troubleshooting

### Build Fails
```bash
# Clear cache and rebuild
rm -rf .next
npm run build
```

### API Errors
- Verify `.env.local` exists
- Check API keys are valid
- Ensure keys don't have extra spaces

### Memory Not Loading
- Check Hindsight token
- Verify network connection
- Try running seed again

### UI Issues
- Hard refresh: `Cmd+Shift+R` (Mac) or `Ctrl+F5` (Windows)
- Clear browser cache
- Try incognito mode
